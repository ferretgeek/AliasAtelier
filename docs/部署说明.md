# 部署说明 / Deployment

## 选择方式

| 场景 | 推荐方式 | 端口 |
| --- | --- | --- |
| 自己电脑临时使用 | Python 标准库服务器 | `127.0.0.1:4173` |
| 家庭服务器或 NAS | Docker Compose | `8080` |
| 公网长期访问 | Docker + HTTPS 反向代理 | 由代理决定 |

应用是纯静态站点，邮箱内容只在访问者的浏览器中处理。部署服务器不会接收输入数据。

## 本地运行

需要 Python 3.10 或更高版本：

```bash
python scripts/serve.py
```

默认只监听 `127.0.0.1`。局域网共享时才显式使用：

```bash
python scripts/serve.py --host 0.0.0.0 --port 4173
```

这会让同一网络中的设备可以访问；请同时检查 Windows 防火墙和网络是否可信。

## Docker Compose

```bash
docker compose up -d --build
docker compose ps
```

打开 `http://服务器地址:8080`。容器使用非 root Nginx、只读文件系统、全部 capability 删除和 `no-new-privileges`。

停止：

```bash
docker compose down
```

更新：

```bash
git pull --ff-only
docker compose up -d --build
```

## HTTPS 反向代理

公网访问建议由 Caddy、Nginx、Traefik 或 Cloudflare Tunnel 提供 HTTPS，再反向代理到 `127.0.0.1:8080`。应用本身不需要环境变量、数据库或秘密。

反向代理必须保留或补上这些响应头：

```text
Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

不要为了嵌入统计、远程字体或在线 API 而放宽 `connect-src 'none'`；这会改变项目“零上传”的隐私承诺。

## 健康检查与日志

- 健康检查：`GET /healthz`，成功时返回 `ok`。
- 应用没有后端业务日志，因此不会记录邮箱内容。
- Web 服务器仍可能记录访问 IP、路径与 User-Agent；如不需要，应在反向代理层关闭或缩短访问日志保留期。

## 升级、备份与恢复

- 升级前保留当前源码或容器镜像标签；新版本先在另一端口打开并完成一次生成、复制和 TXT 下载，再切换反向代理。
- 应用没有数据库，邮箱输入也不进入 `localStorage`；只持久化主题名称。需要保留结果时，在页面内下载 TXT。服务器端无需备份用户内容。
- 回滚只需恢复旧静态文件或旧镜像。若要恢复主题，重新选择即可；浏览器站点数据不能恢复未下载的输入。

Before upgrading, retain the previous source or image tag and verify generation, copy, and TXT download on a separate port. The app has no database and does not persist mailbox input; only the theme name is stored. Keep results by downloading TXT. Rollback restores the previous static bundle or image.

## 卸载与故障排查

- 本地：停止 `scripts/serve.py` 后删除项目目录；可在浏览器站点设置中清除主题。
- Docker：运行 `docker compose down`，确认不再需要回滚后再删除本地镜像。
- 页面无法加载：检查 `/healthz`、静态资源返回码和 CSP 控制台错误。
- 按钮不可用：输入为空或存在未通过校验的邮箱时属于正常禁用状态；修正输入后再试。
- 反向代理下图标或样式 404：确认代理保留相对路径，并清理旧缓存。

For removal, stop the local server or run `docker compose down`; clear browser site data only if the saved theme is no longer needed. For failures, check `/healthz`, static asset status codes, CSP errors, validation messages, proxy path handling, and stale caches.

## Deployment summary

Run `python scripts/serve.py` for a loopback-only local server, or `docker compose up -d --build` for a hardened static container on port `8080`. Put an HTTPS reverse proxy in front of any public deployment, preserve the strict CSP, and avoid adding analytics or remote assets that would invalidate the local-only data model.
