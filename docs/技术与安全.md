# 技术与安全 / Technical & Security

## 架构

别名工坊把数据处理层与静态交付层分开：

```text
TXT / 粘贴内容
      ↓ File API / textarea
alias-core.js（解析、校验、去重、生成）
      ↓
安全遮挡预览 ── 用户明确操作 ──→ 剪贴板或本地 TXT

Python / Nginx：只交付固定静态文件，不接收业务数据
```

浏览器核心使用无依赖 JavaScript，Node 测试直接加载同一个 `alias-core.js`，避免“测试了另一份实现”。Python 服务器使用固定路由白名单，不提供目录列表，也不会把 URL 映射到任意文件系统路径。

## 输入模型

支持三种记录：

1. 单个邮箱地址。
2. `邮箱----附加字段`；分隔符后的内容被当作不透明字符串。
3. Gmail 双行记录；第一行是邮箱，第二行是不透明附加字段。

自动双行模式只对 Gmail 生效，避免把 Microsoft 邮箱后的普通说明误认成密码。无效行会统计并跳过，不会悄悄混入导出。

## 生成规则

- 结果格式为 `local+prefixN@domain`。
- 已带 `+` 的地址跳过，避免嵌套标签。
- 结果按大小写不敏感方式去重。
- 前缀只接受 1–24 位 ASCII 字母、数字、下划线和连字符。
- 单邮箱数量限制为 1–50000，单次总别名限制为 200000。
- 自动模式只接受 Gmail 和 Microsoft；iCloud 与任意域名需要显式选择。

## 威胁模型

### 假设

- 输入可能包含真实密码、应用密码、OAuth 客户端字段或刷新令牌。
- 用户可能误把带秘密的 TXT 拖入页面。
- 公开仓库可能被自动扫描全部文件、提交历史、图片、Release 和 Actions 日志。
- 部署站点可能位于不受完全信任的服务器上。

### 主要控制

| 风险 | 控制 |
| --- | --- |
| 页面把输入发到外网 | HTML 与服务器响应均设置 `connect-src 'none'`，且没有外部脚本、字体或图片 |
| 数据残留 | 不持久化源文本或结果；仅主题名进入 `localStorage` |
| 屏幕旁观或截图泄露 | 附加字段在预览中始终替换为遮罩 |
| 默认导出秘密 | “保留附加字段”默认关闭，并在开启后持续显示警告 |
| 超大任务卡死浏览器 | 文件 5 MB、单邮箱 50000、总别名 200000 三层上限 |
| 路径遍历 | Python 服务器只提供固定路径白名单 |
| 误提交私人 TXT | `.gitignore` 忽略 TXT 和常见私有/数据/导出目录 |
| 依赖供应链 | 浏览器与 Python 运行时均无第三方依赖；CI Action 固定到完整提交 SHA |

## 已知边界

- CSP 能阻止网页脚本主动联网，但无法保护已经被恶意浏览器扩展、系统级木马或剪贴板监控读取的数据。
- 下载、复制后，内容已经离开页面内存，用户需自行保护文件与剪贴板。
- `+tag` 是收件地址规则，不是新账号；目标站点可能拒绝它，邮件服务商也可能不支持。
- Apple 当前公开的是手动创建的 iCloud 别名与 Hide My Email，因此 iCloud 动态标签只作为待验证候选生成。

## 发布门禁

每个公开版本至少检查：

1. Node 核心测试与 Python 服务器测试。
2. Python 编译、Ruff 与 Bandit。
3. pip-audit（运行时依赖应为零）。
4. detect-secrets 与 Gitleaks 工作树扫描。
5. 全部可达 Git 历史的 Gitleaks 扫描。
6. TXT、环境文件、绝对路径、私人邮箱、域名、IP、账号标识与凭据模式的自定义复查。
7. 预览图画面与 PNG 元数据检查。
8. 公开克隆后的相同扫描、测试、提交身份与标签指向复核。

## English summary

Alias Atelier processes every input in the browser using the same dependency-free core tested by Node. Static servers expose only an allowlist of files. A strict `connect-src 'none'` CSP, default metadata removal, permanently masked previews, bounded workloads, and history-aware release scans form the privacy boundary. The design does not protect a compromised browser, extension, operating system, clipboard, or downloaded export.
